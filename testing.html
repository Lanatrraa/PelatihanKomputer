Pelajari Materi
Word

Microsoft Word

Microsoft Word adalah aplikasi pengolah kata (word processor) yang digunakan untuk membuat, mengedit, dan memformat dokumen teks secara profesional. Aplikasi ini sangat penting bagi mahasiswa untuk menyusun berbagai dokumen akademik.

Mahasiswa diharapkan mampu menyusun dokumen yang sistematis, rapi, dan sesuai dengan kaidah penulisan akademik seperti makalah, laporan, dan skripsi.

Fitur Utama yang Dipelajari:

Formatting

Pengaturan teks, paragraf, margin, dan ukuran kertas.

Styles & Heading

Membuat dokumen terstruktur untuk daftar isi otomatis.

Objects

Penyisipan tabel, gambar, grafik, dan simbol.

Academic Tools

Header, footer, penomoran halaman, dan daftar pustaka.

Cloud Based

Google Sheets

Google Sheets adalah aplikasi pengolah angka (spreadsheet) berbasis cloud yang dikembangkan oleh Google. Aplikasi ini memungkinkan mahasiswa mengolah data secara online dan terintegrasi langsung dengan akun Google tanpa perlu instalasi software.

Fungsi Utama Google Sheets

📊
Manajemen Data

Menyusun data nilai, jadwal kuliah, dan data penelitian dalam bentuk tabel yang rapi.

👥
Kolaborasi Real-Time

Bekerja pada file yang sama bersama teman kelompok secara bersamaan tanpa kirim file berulang kali.

☁️
Akses Berbasis Cloud

File tersimpan otomatis di Google Drive, mencegah kehilangan data dan dapat diakses dari mana saja.

🔗
Ekosistem Google

Integrasi penuh dengan Google Forms untuk pengumpulan survei dan Google Docs untuk laporan.

Berbagi dan Kontrol Akses

Mahasiswa dapat mengatur hak akses file secara fleksibel:

👁️ Viewer 💬 Commenter ✏️ Editor
Visual Media

Microsoft PowerPoint

Presentasi PowerPoint adalah media presentasi digital yang digunakan untuk menyampaikan informasi secara visual, terstruktur, dan menarik. Aplikasi ini adalah standar utama dalam kegiatan akademik seperti seminar, diskusi kelas, dan ujian presentasi.

Fungsi Utama PowerPoint

📊 Visualisasi Data

Meringkas materi panjang menjadi poin-poin penting menggunakan grafik, diagram, dan tabel.

🏗️ Struktur Sistematis

Menyusun urutan slide secara logis agar informasi mudah dipahami oleh audiens.

✨ Daya Tarik Visual

Menggunakan tema, transisi, dan animasi untuk menjaga perhatian audiens tetap fokus.

📽️ Integrasi Media

Menyisipkan audio, video, dan hyperlink untuk presentasi yang lebih interaktif.

💡 Tips Kerja Kelompok: File PowerPoint dapat dikerjakan bersama secara offline maupun online, memudahkan kolaborasi tugas laporan atau penelitian tim.

Kesimpulan: PowerPoint membantu mahasiswa meningkatkan kemampuan komunikasi akademik dan profesional melalui penyampaian informasi yang jelas dan efektif.

Creative Tool

Canva for Education

Canva adalah aplikasi desain grafis berbasis online yang memudahkan mahasiswa membuat materi visual profesional tanpa perlu keahlian desain rumit. Sangat ideal untuk pembuatan poster, infografis, dan media pembelajaran interaktif.

🎨
Template Praktis

Ribuan template siap pakai untuk presentasi dan poster akademik.

✨
Elemen Visual

Akses ke jutaan ikon, ilustrasi, dan font premium untuk mempercantik tugas.

🤝
Kolaborasi Tim

Fitur pengeditan bersama secara real-time untuk pengerjaan tugas kelompok.

📥
Multi-Format

Ekspor hasil desain ke format PDF, PPT, JPG, hingga video MP4.

Penyimpanan Berbasis Cloud

Desain tersimpan otomatis dan dapat diakses melalui browser atau aplikasi mobile kapan pun Anda butuhkan.

Kesimpulan: Canva membantu mahasiswa meningkatkan kualitas visual tugas kuliah agar informasi tersampaikan secara lebih menarik dan efektif.
